## Задание 2: быстрый локальный запуск

Нужны Python 3.9+, `make` и компилятор C++17. Команды выполняются из корня репозитория.

Поднять основную змейку Viper 0.2:

```sh
python3 task-2/run_local.py serve
```

Скрипт сам соберёт движок и запустит [сервер на порту 8000](http://127.0.0.1:8000).
Остановка — `Ctrl+C`.

Провести 11 локальных тренировочных дуэлей с автоматическим запуском и остановкой серверов:

```sh
python3 task-2/run_local.py demo
```

При первом прогоне нужен интернет для скачивания официального CLI.
Отчёты и повторы сохраняются в `task-2/local/`. Соперники тренировочные, не эталоны курса.
Подробности и запуск с рабочим бюджетом 280 мс — в [README задания 2](task-2/README.md).
