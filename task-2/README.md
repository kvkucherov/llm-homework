# Задание 2: Battlesnake — Viper 0.2

Собственная змейка: поиск на C++17 и HTTP API на Python без pip-зависимостей.
Основной режим — Standard Duels 11×11. Это текущая основная версия:
последующие эксперименты не показали устойчивого усиления и сюда не включены.

## Поднять змейку локально

Нужны Python 3.9+, `make` и компилятор C++17. На macOS компилятор и `make`
устанавливаются через `xcode-select --install`, если их ещё нет.
Из корня репозитория:

```sh
cd task-2
python3 run_local.py serve
```

Скрипт сам соберёт движок. Адрес: http://127.0.0.1:8000, проверка состояния:
http://127.0.0.1:8000/health. Остановка — `Ctrl+C`.
Сервер использует 280 мс на ход в одном потоке, с пределом глубины 32 полных
хода; выбирается результат последней завершённой глубины. Все команды ниже
выполняются из `task-2/`.

## Прогнать против локальных змеек

Серверы можно не запускать вручную:

```sh
python3 run_local.py demo
```

Команда собирает змейку, поднимает временные серверы, проводит 11 дуэлей
через официальный Battlesnake CLI и останавливает серверы. При первом запуске
нужен интернет: CLI v1.2.3 скачивается с GitHub с проверкой SHA-256.
Автозагрузка CLI поддерживает macOS и Linux на arm64 и x86_64.
Отчёт и повторы сохраняются в `local/<время-запуска>/`.

По умолчанию это быстрая тренировка против `territory` с бюджетом 20 мс.
Для рабочего бюджета и другого тренировочного соперника:

```sh
python3 run_local.py demo --budget-ms 280
python3 run_local.py demo --policy hunter
```

Доступны `greedy`, `cautious`, `territory`, `hunter`. Сравнить со всеми четырьмя
в нашем локальном симуляторе, по 8 игр с перестановкой стартовых сторон:

```sh
python3 -m tools.benchmark --games 8 --budget-ms 20 --report local/practice.json
```

Это наши тренировочные боты, **не эталоны курса** Novice / Apprentice /
Journeyman / Expert. Победы в тренировках не подтверждают 60 баллов.
Для проверки настоящих эталонов нужны их API-адреса: заполните
`references.json` по `references.example.json` и запустите
`python3 run_local.py course`. Ссылки на профили арены не подходят.

## Проверки и повторы

```sh
make test
```

Проверяются правила, тактика, лимит времени, большой размер поля и локальный
запуск; быстрый расчёт пространства сверяется с независимым обходом клеток.
При работающем сервере можно проверить HTTP и задержку:

```sh
python3 -m tools.validate_http --report local/http.json
```

Для просмотра записи из папки локального прогона:

```sh
python3 -m tools.replay local/ИМЯ_ПРОГОНА/game-01.jsonl
```

Откройте полученный `replays/latest.html` в браузере. Сборки, скачанный CLI,
личные API-адреса, отчёты и повторы исключены из Git.

## Стратегия и ограничения

Точные одновременные переходы, maximin, alpha-beta, итеративное углубление,
таблица состояний, битовые маски и оценка доступного пространства, длины,
еды и контроля проходов. Поиск не знает будущую случайную еду и будущую
сторону сжатия Royale. Основной проверенный режим — Standard Duels;
для Wrapped и Constrictor есть проверки переходов.

Код решения написан для этого задания, код чужих соревновательных змеек
не использован. Официальный CLI используется отдельным процессом;
его лицензия AGPL-3.0 сохраняется при скачивании в `vendor/battlesnake/`.
